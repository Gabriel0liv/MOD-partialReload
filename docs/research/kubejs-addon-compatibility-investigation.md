# Compatibilidade de addons KubeJS

Nenhum addon KubeJS foi encontrado no userdev ou workspace. O source disponível inclui schemas/mappings próprios, mas isso não comprova Create, Ars Nouveau, Botania, Thermal, LootJS ou MoreJS para Forge 1.20.1. Todos permanecem `UNKNOWN`/`UNSUPPORTED` até JARs da versão alvo serem testados individualmente.
